# 智能取数接口文档

## GET /xdc/context

列出跨域调度当前识别到的数据节点和已注册数据集，用于环境检查及原型中的数据资源、数据节点基础展示。

Request

无请求体。

Response

```json
{
  "message": "success",
  "result": {
    "local_center_id": "10.0.1.10",
    "default_center_id": "10.0.1.10",
    "centers": [
      {
        "center_id": "10.0.1.10",
        "center_name": "数据节点A"
      }
    ],
    "datasets": [
      {
        "dataset_id": "dataset-001",
        "name": "示例数据集",
        "description": "数据集描述",
        "tags": ["中文", "PDF"],
        "facets": {
          "field": ["科技文献"],
          "language": ["中文"],
          "rawFormat": ["PDF"]
        },
        "access": {
          "skill": "完整算子类路径",
          "param": "dataset_id",
          "output_param": "output"
        },
        "replicas": [
          {
            "replica_id": "replica-001",
            "source_ip": "10.0.1.10",
            "locator": "dataset-001",
            "status": "AVAILABLE",
            "metrics": {}
          }
        ]
      }
    ]
  },
  "code": 200
}
```

说明：

- `facets` 为动态注册字段，不能按固定学科字段解析。
- `locator` 是后端内部定位信息，不保证是HTTP下载地址。
- 该接口当前不支持搜索和分页。

## POST /xdc/plan/stream

根据用户自然语言需求生成跨域数据获取方案，并通过SSE返回规划过程。原型中的“智能取数”优先调用该接口。

Request

```json
{
  "user_request": "选择三份相关语料并合并为 result.tar",
  "detail": false
}
```

Response

Content-Type：`text/event-stream`

规划开始：

```text
data: {"type":"status","stage":"started"}
```

阶段开始：

```text
data: {"type":"stage","stage":"intent","status":"started"}
```

阶段完成：

```text
data: {"type":"stage","stage":"intent","status":"finished","summary":"识别出 3 项需求条件 · 命中 2 个数据集"}
```

最终完成：

```text
data: {"type":"done","plan":{"plan_id":"xdc-123456789abc","mode":"composition"}}
```

异常：

```text
data: {"type":"error","message":"错误信息"}
```

可能出现的阶段：

| stage | 说明 |
|---|---|
| `intent` | 意图识别和需求理解 |
| `satisfaction` | 数据需求满足分析 |
| `access` | 直接获取的数据副本选择 |
| `planning` | DAG规划 |
| `expand` | 逻辑DAG展开 |
| `bind` | 算子与数据节点绑定 |
| `segment` | 跨域DAG划分 |
| `nest` | 子DAG嵌套 |
| `validate` | 方案校验 |
| `unavailable` | 当前没有可用数据 |

最终 `plan.mode` 有三种：

```text
direct       单个数据集可以直接满足需求
composition  需要多个数据集和DAG加工
unavailable  当前没有满足需求的数据
```

- `dag.nodes` 和 `dag.edges` 数量不固定，必须按返回结果动态处理。

## GET /xdc/plan/{plan_id}

根据 `plan_id` 查询已经生成的方案。

Request

Path参数：

```text
plan_id=xdc-123456789abc
```

Query参数：

```text
detail=false
```

完整示例：

```http
GET /xdc/plan/xdc-123456789abc?detail=false
```

Response

```json
{
  "message": "success",
  "result": {
    "plan_id": "xdc-123456789abc",
    "mode": "composition",
    "conclusion": "需要组合多个数据集并执行加工流程",
    "validation": {
      "ok": true,
      "errors": [],
      "warnings": []
    },
    "requirement": {},
    "coverage": {},
    "sources": [],
    "dag": {}
  },
  "code": 200
}
```

计划不存在或已过期时返回404：

```json
{
  "detail": "计划不存在或已过期: xdc-123456789abc"
}
```

## POST /xdc/handoff

执行引擎交接自检。检查生成的嵌套DAG能否被执行引擎转换和构图，不会真正提交任务。

Request

```json
{
  "plan_id": "xdc-123456789abc"
}
```

Response

```json
{
  "message": "success",
  "result": {
    "plan_id": "xdc-123456789abc",
    "ok": true,
    "转换已执行": true,
    "构图已执行": true,
    "最外层绑定位置": "10.0.2.10",
    "根提交地址已确定": true,
    "层数": 2,
    "失败层数": 0,
    "layers": [],
    "说明": []
  },
  "code": 200
}
```

前端主要判断：

```text
result.ok == true
```
