# chemical_expression_normalizer 化学表达式规范化算子

## 功能概述

读取 UTF-8 文本并规范化其中的化学专业表达式。算子将可识别化学式中的元素符号调整为标准大小写，将化学计量数字转换为带花括号的下标，将离子电荷转换为带花括号的上标，并统一反应箭头和化学键写法。

## 触发条件

- 化学表达式规范化
- 化学式或分子式大小写、下标统一
- 化学反应方程式箭头和排版统一
- 离子电荷、化学键标注规范化
- 化工、材料科研文本格式标准化

## 处理逻辑

1. 移除零宽字符、字节顺序标记等不可见干扰字符，并将不换行空格转换为空格。
2. 将 Unicode 下标和化学式中的连续计量数字统一为 `_{...}`；不改动方程式前的计量系数。
3. 将 Unicode 上标和常见电荷标注统一为 `^{...}`，保留电荷数值与正负号。
4. 对具备明确化学式特征的片段按元素周期表规范元素符号大小写；标准大小写、全大写和小写/混合写法采用不同的安全分词规则，优先保留原有元素边界并降低稀有元素误判。
5. 将反应操作数之间的单向箭头统一为 `->`、可逆箭头统一为 `<->`；只在两个标准元素符号之间规整异体单键和三键，避免改写普通正文破折号。

## 使用方法

```bash
python scripts/chemical_expression_normalizer.py \
  --input_path {input_path} \
  --output_path {output_path}
```

## 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--input_path` | 是 | 包含化学表达式的 UTF-8 文本文件路径。 |
| `--output_path` | 是 | 规范化文本文件的输出路径；缺失的父目录会自动创建。 |

## 输出示例

```text
输入: h2so4 + Na⁺ → na2so4 + h2↑；Fe≡C，SO4²⁻
输出: H_{2}SO_{4} + Na^{+} -> Na_{2}SO_{4} + H_{2}↑；Fe#C，SO_{4}^{2-}
```

## 注意事项

- 仅处理 UTF-8 纯文本文件，保留原始换行结构。
- 元素符号大小写只对具备计量数字、标准元素大小写或反应操作数位置等明确特征的片段进行调整；普通英文单词和字母数字编码不作为化学式强制改写。
- 无大小写边界的字符串可能存在化学歧义：全大写串优先保留逐个大写元素边界，小写或混合串优先选择元素数量更少且不含稀有元素的合法分词；无法可靠分词时保持原文。
- 本算子不执行化学方程式配平、物质命名、分子结构推断、反应条件修改或语义校正。
- 化学式使用 `_{...}` 和 `^{...}` 文本标记表示下标与上标，调用方需确保后续流程支持该表示。

## 脚本说明

入口脚本 `scripts/chemical_expression_normalizer.py` 仅使用 Python 标准库完成文本读写和规则处理。
